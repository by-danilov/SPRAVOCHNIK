# Корпоративный веб-справочник сотрудников

**SPRAVOCHNIK** — это веб-приложение для централизованного управления данными о сотрудниках компании. Система позволяет быстро находить контактную информацию, управлять штатом через удобную админ-панель и автоматизировать рутинные задачи по бэкапу данных.

## 🚀 Основные возможности

### Для пользователей:
* **Универсальный поиск:** Поиск сотрудников по ФИО, должности, городу, филиалу или email (регистронезависимый).
* **Адаптивный интерфейс:** Корректное отображение на ПК, планшетах и смартфонах (Bootstrap 5).
* **Система предложений:** Возможность инициировать исправление устаревших данных через специальную форму.

### Для администраторов:
* **Полный CRUD:** Управление записями сотрудников.
* **Импорт/Экспорт Excel:** Массовая загрузка данных из `.xlsx` файлов и выгрузка актуальной базы.
* **Модерация правок:** Специализированный интерфейс для утверждения или отклонения предложений от пользователей.
* **Автоматизация:** Автоматическое применение одобренных правок в карточку сотрудника.

### Фоновые задачи:
* **Scheduled Backup:** Автоматический экспорт всей базы данных в Excel 1-го и 15-го числа каждого месяца.
* **Email-рассылка:** Отправка сформированного бэкапа на корпоративный архивный email.

## 🛠 Технологический стек

* **Backend:** Python 3.11+, Django 4.2+
* **Database:** PostgreSQL
* **Task Queue:** Celery + Redis
* **Frontend:** HTML5, CSS3 (Bootstrap 5), JavaScript
* **Dependency Management:** Poetry
* **Excel Processing:** Openpyxl, Django-import-export

## 📋 Требования к данным (Валидация)

Система реализует строгую двухуровневую проверку данных:
1. **Телефоны:** Обязательное наличие хотя бы одного номера (личного или рабочего). Валидация формата (цифры и символы `+`, `(`, `)`, `-`).
2. **Email:** Проверка корректности формата рабочей почты.
3. **Целостность:** Запрет на повторное изменение уже обработанных (принятых/отклоненных) заявок на исправление.



## 🔧 Установка и запуск

### 1. Клонирование репозитория
```bash


git clone https://github.com/by-danilov/SPRAVOCHNIK
cd SPRAVOCHNIK
2. Настройка окружения (Poetry)

poetry install
poetry shell
3. Переменные окружения
Создайте файл .env в корне проекта и заполните его:

Фрагмент кода

DEBUG=True
SECRET_KEY=your_secret_key
DB_NAME=spravochnik_db
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432

4. Миграции и создание администратора

python manage.py migrate
python manage.py createsuperuser
5. Запуск сервисов
Для полной функциональности необходимо запустить три процесса:

Django сервер:

python manage.py runserver
Redis (Брокер): Должен быть запущен в системе (порт 6379).

Celery Worker & Beat (для бэкапов):

celery -A config worker --loglevel=info
celery -A config beat --loglevel=info

📂 Структура проекта

config/ — настройки проекта, Celery и URL.

core/ — основное приложение (модели, формы, задачи, представления).

templates/ — HTML-шаблоны (Base, Employee list, Proposal form).

static/ — статические файлы (CSS/JS).
